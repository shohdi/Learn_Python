## 1. أعطِ برنامجك صوتًا: print() (دقيقتان) 📣

`print()` هي **دالة (Function)** جاهزة: أداة لها اسم وتؤدي مهمة. مهمتها عرض القيم الموجودة بين القوسين على الشاشة. لا تحتاج ورقًا أو طابعة، ميزانية الحبر في أمان! 😄

```python
print("Hello, Python!")
print(25)
print("Score:", 25)
```

الناتج:

```text
Hello, Python!
25
Score: 25
```

نضع النص بين علامتي اقتباس متطابقتين، مثل `"hello"` أو `'hello'`. أما الأعداد التي نستخدمها في الحساب فلا تحتاج اقتباسًا. افتراضيًا، تفصل `print()` بين القيم المفصولة بفواصل بمسافة، وتنتقل إلى سطر جديد عند الانتهاء.

## 2. المتغيرات: أسماء للقيم (3 دقائق) 🏷️

**المتغير (Variable)** اسم يشير إلى قيمة لنستخدمها لاحقًا. تخيّله بطاقة اسم نضعها على معلومة.

```python
student_name = "Mona"
age = 20
height = 1.65
print(student_name)
print("Age:", age)
```

الناتج:

```text
Mona
Age: 20
```

هنا `"Mona"` نص (**String** أو `str`)، و`20` عدد صحيح (**Integer** أو `int`)، و`1.65` عدد ذو فاصلة عشرية (**Float**). لاحظ أننا نكتب الفاصلة العشرية في الكود بنقطة.

تعني العلامة `=` **الإسناد (Assignment)**: احسب قيمة الطرف الأيمن واربطها بالاسم الموجود على اليسار. إنها لا تسأل إن كان الطرفان متساويين.

```python
age = 20
age = age + 1
print(age)
```

الناتج: `21`. تقرأ بايثون القيمة القديمة، وتضيف إليها واحدًا، ثم تسند النتيجة إلى `age`. مبروك: عيد ميلاد دون كعكة! 🎂

اختر أسماء واضحة مثل `student_name` و`total_price`. يمكن أن يحتوي الاسم حروفًا وأرقامًا وشرطة سفلية، لكنه لا يبدأ برقم ولا يحتوي مسافات. الأسماء حساسة لحالة الأحرف: `age` و`Age` اسمان مختلفان. تجنّب الكلمات المحجوزة مثل `class`، وأسماء الأدوات التي نحتاجها مثل `print`.

يعرض `print("age")` كلمة `age` نفسها، بينما يعرض `print(age)` قيمة المتغير. علامتا الاقتباس تغيّران المعنى!

## 3. العمليات: بايثون آلة حاسبة (4 دقائق) 🧮

**المعامل (Operator)** رمز ينفّذ عملية. أما **التعبير (Expression)**، مثل `3 + 2`، فينتج قيمة.

| المعامل | المعنى | المثال | الناتج |
| --- | --- | --- | --- |
| `+` | الجمع | `7 + 2` | `9` |
| `-` | الطرح | `7 - 2` | `5` |
| `*` | الضرب | `7 * 2` | `14` |
| `/` | القسمة | `7 / 2` | `3.5` |
| `//` | القسمة مع التقريب لأسفل | `7 // 2` | `3` |
| `%` | باقي القسمة | `7 % 2` | `1` |
| `**` | الأس | `2 ** 3` | `8` |

مع الأعداد الصحيحة الموجبة، يحسب `//` عدد المجموعات الكاملة، ويعطينا `%` الباقي. سبع قطع بسكويت لشخصين: ثلاث لكل شخص وقطعة للمدرّس. قسمة عادلة جدًا! 🍪

بدقة أكثر، يقرّب `//` ناتج القسمة إلى العدد الصحيح الأدنى: نتيجة `-7 // 2` هي `-4`. أما القسمة العادية `/` فتعطي عددًا من نوع `float` حتى في `8 / 2`، إذ تكون النتيجة `4.0`.

تتحكم الأقواس في ترتيب الحساب. في أمثلة الأعداد الموجبة هنا، يأتي الأس قبل الضرب والقسمة وباقي القسمة، وتأتي هذه العمليات قبل الجمع والطرح.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

الناتج:

```text
14
20
```

تؤثر علامات الاقتباس في العمليات أيضًا:

```python
print(5 + 3)
print("5" + "3")
```

الناتج:

```text
8
53
```

مع الأعداد، يجمع `+` القيم. ومع النصوص، يصل النصوص ببعضها.

## 4. أمثلة محلولة (3 دقائق) ✅

### المثال الأول: فاتورة مقهى صغيرة ☕

**المطلوب:** سعر المشروب 12 ريالًا. اشترِ ثلاثة مشروبات، واطرح خصمًا قدره 5 ريالات من كامل الطلب، ثم اعرض الإجمالي.

```python
drink_price = 12
quantity = 3
discount = 5
total = drink_price * quantity - discount
print("Total:", total, "SAR")
```

الناتج:

```text
Total: 31 SAR
```

**الشرح:** نحسب أولًا `12 * 3 = 36`، ثم نطرح `5`. يحصل المتغير `total` على القيمة `31`.

### المثال الثاني: دقائق وثوانٍ متبقية ⏱️

**المطلوب:** حوّل 135 ثانية إلى دقائق كاملة وثوانٍ متبقية.

```python
total_seconds = 135
minutes = total_seconds // 60
seconds = total_seconds % 60
print("Minutes:", minutes)
print("Seconds:", seconds)
```

الناتج:

```text
Minutes: 2
Seconds: 15
```

**الشرح:** يحتوي العدد 135 على مجموعتين كاملتين من 60، ويتبقى 15.

## مراجعة سريعة وأخطاء شائعة 🎯 (دقيقة)

تعرض `print()` القيم، وتمنح المتغيرات أسماءً للقيم، وتحسب المعاملات الحسابية قيمًا جديدة.

- استخدم علامات اقتباس مستقيمة ومتطابقة، ولا تنسَ إغلاق الأقواس.
- أسند قيمة للمتغير قبل استخدامه. عند ظهور `NameError`، راجع كتابة الاسم وحالة الأحرف.
- استخدم `print("Age:", age)` لعرض نص بجانب عدد؛ محاولة وصل نص وعدد باستخدام `+` تسبب `TypeError`.
- القسمة على صفر تسبب `ZeroDivisionError`.

المحاضرة التالية: نجعل المستخدم يشارك في الحوار باستخدام `input()`، ثم نحوّل النص إلى أعداد باستخدام `int()` و`float()`. 🎤
