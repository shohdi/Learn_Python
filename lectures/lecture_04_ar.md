## 1. الشروط والمقارنات (3 دقائق) ❓

**الشرط (Condition)** تعبير يفحصه البرنامج ليقرر ما الذي سيفعله. تنتج مقارناتنا **قيمة منطقية (Boolean)** من النوع `bool`: إما `True`، أي صحيح، أو `False`، أي خطأ.

«هل درجة الحرارة 30 أو أكثر؟» سؤال تستطيع بايثون إجابته. أما «هل الجو جميل؟» فيحتاج تفاصيل أكثر! ☀️

| المعامل | المعنى | المثال | الناتج |
| --- | --- | --- | --- |
| `==` | يساوي | `5 == 5` | `True` |
| `!=` | لا يساوي | `5 != 5` | `False` |
| `>` | أكبر من | `7 > 5` | `True` |
| `<` | أصغر من | `7 < 5` | `False` |
| `>=` | أكبر من أو يساوي | `5 >= 5` | `True` |
| `<=` | أصغر من أو يساوي | `6 <= 5` | `False` |

```python
temperature = 30
is_hot = temperature >= 30
print(is_hot)
print(temperature < 30)
print("tea" == "Tea")
```

الناتج:

```text
True
False
False
```

تُسنِد `=` قيمة، بينما تقارن `==` بين قيمتين. مقارنة النصوص حساسة لحالة الأحرف. اكتب `True` و`False` بحرف أول كبير ودون اقتباس: `"False"` نص، وليست قيمة منطقية.

## 2. if: نفّذ الكود عندما يتحقق الشرط (3 دقائق) 🚦

تنفّذ **جملة `if`** مجموعة تعليمات فقط عندما يكون شرطها صحيحًا.

```python
temperature = 32
if temperature >= 30:
    print("It is hot!")
    print("Bring some water.")
print("Weather check complete.")
```

الناتج:

```text
It is hot!
Bring some water.
Weather check complete.
```

تبدأ النقطتان الرأسيتان (`:`) **كتلة (Block)**، وهي مجموعة تعليمات مرتبطة ببعضها. تحدد **المسافة البادئة (Indentation)**، أي المسافات في بداية السطر، التعليمات التابعة لهذه الكتلة. استخدم أربع مسافات في بداية كل سطر داخل الكتلة هنا.

رسالتا الطباعة اللتان تسبقهما مسافات تابعتان لـ `if`. أما `print()` الأخيرة فتبدأ في مستوى `if` نفسه، ولذلك تُنفَّذ بعد الفحص سواء كان الشرط صحيحًا أم خطأ. غيّر `temperature` إلى `25` وسيكون الناتج الوحيد `Weather check complete.`

أصبح للمسافات عمل تؤديه؛ لم تعد مجرد زينة للصفحة! 😄

## 3. else وelif: اختر مسارًا (3 دقائق) 🛤️

توفر **`else`** بديلًا عندما يكون شرط `if` خطأ. نكتب بعدها نقطتين رأسيتين، لكن لا نضيف إليها شرطًا.

```python
score = 45
if score >= 50:
    print("Pass")
else:
    print("Keep practicing")
```

الناتج:

```text
Keep practicing
```

تُنفَّذ واحدة فقط من الكتلتين. الدرجة `50` بالضبط تسلك مسار `if` لأن `>=` تشمل المساواة.

أما **`elif`**، وهي اختصار لعبارة «else if»، فتفحص شرطًا آخر عندما تكون الشروط السابقة خطأ.

```python
score = 85
if score >= 90:
    print("Excellent")
elif score >= 50:
    print("Pass")
else:
    print("Keep practicing")
```

الناتج:

```text
Pass
```

تفحص بايثون الشروط من الأعلى إلى الأسفل، وتنفّذ فقط **كتلة أول شرط يتحقق** في هذه السلسلة. إن لم يتحقق أي شرط، تنفّذ `else`. يمكن كتابة عدة كتل `elif`، أما `else` فهي اختيارية وتأتي أخيرًا. اجعل `if` و`elif` و`else` على مستوى المسافة البادئة نفسه.

الترتيب مهم: افحص `>= 90` قبل `>= 50`، وإلا ستطابق الدرجة `95` الحد الأدنى أولًا. أما جمل `if` المنفصلة فتُفحص بشكل مستقل، وقد تُنفَّذ أكثر من كتلة منها.

## 4. أمثلة محلولة (3 دقائق) ✅

### المثال الأول: خصم المقهى ☕

**المطلوب:** امنح خصمًا قدره 5 ريالات للطلبات بقيمة 30 ريالًا أو أكثر. بخلاف ذلك، أبقِ الإجمالي كما هو. اعرض السعر النهائي.

```python
total = 36
if total >= 30:
    total = total - 5
print("Total:", total, "SAR")
```

الناتج:

```text
Total: 31 SAR
```

**الشرح:** الشرط `36 >= 30` صحيح، لذلك تطرح بايثون 5. تُنفَّذ `print()` الأخيرة بعد الفحص. إذا بدأ الإجمالي عند `30` يصبح `25 SAR`، وإذا بدأ عند `29` يبقى `29 SAR`. لا نحتاج `else` لأنه لا يوجد عمل إضافي عندما يكون الشرط خطأ.

### المثال الثاني: زوجي أم فردي؟ 🔢

**المطلوب:** حدد إن كان عدد صحيح زوجيًا أم فرديًا.

```python
number = 7
if number % 2 == 0:
    print("Even")
else:
    print("Odd")
```

الناتج:

```text
Odd
```

**الشرح:** يعطي `%` باقي القسمة، كما تعلمنا في المحاضرة الثالثة. باقي قسمة 7 على 2 هو 1، لذلك تكون مقارنته بالصفر خطأ. جرّب `8` و`0`: كلاهما يعطي `Even`، أي زوجي.

## مراجعة سريعة وأخطاء شائعة (دقيقة) 🎯

تنتج المقارنات `True` أو `False`. استخدم `if` لتنفيذ عمل بشرط، و`elif` لفحص شرط آخر، و`else` للحالة المتبقية.

- استخدم `==` للمقارنة، وليس `=`.
- ضع `:` في نهاية سطر كل من `if` و`elif` و`else`.
- استخدم أربع مسافات بانتظام داخل الكتل، وتجنّب خلط المسافات بعلامات الجدولة (Tab).
- اكتب `elif` وليس `else if`، ولا تضف شرطًا بعد `else`.
- اختبر القيمة عند الحد بالضبط: لا تشمل `>` المساواة، بينما تشملها `>=`.
- قارن الأعداد بأعداد. نتيجة `"20" == 20` هي خطأ؛ وتسبب `"20" > 10` الخطأ `TypeError` لأنها تحاول تحديد ترتيب بين نص وعدد.

**توزيع الوقت:** 3 + 3 + 3 + 3 + 2 + 1 = 15 دقيقة.
