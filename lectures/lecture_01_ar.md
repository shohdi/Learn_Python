# المحاضرة الأولى: الملفات والمجلدات والطرفية في macOS 🗂️

**المدة المتوقعة:** 15 دقيقة  
**المستوى:** مبتدئ تمامًا  
**الهدف:** فهم الملفات والمجلدات، وفتح الطرفية، والتنقل في الحاسوب، وإنشاء العناصر ونسخها بأمان.

## 1. خزانة ملفات الحاسوب (3 دقائق) 🗄️

**الملف (File)** هو جزء من المعلومات المحفوظة وله اسم. الصورة والأغنية وبرنامج بايثون والمستند النصي كلها ملفات.

أمثلة:

- `cat.jpg` — ملف صورة
- `shopping_list.txt` — ملف نصي
- `hello.py` — ملف بايثون

الجزء الذي يأتي بعد آخر نقطة يسمى **امتداد الملف (File Extension)**. يساعدنا ويساعد الحاسوب على معرفة نوع الملف. تغيير اسم `cat.jpg` إلى `cat.py` لن يحوّل القطة إلى مبرمجة، للأسف! 🐈‍⬛

**المجلد (Folder)**، ويسمى أيضًا **الدليل (Directory)**، هو حاوية تنظم الملفات والمجلدات الأخرى. مثلًا:

```text
Documents/
└── PythonCourse/
    ├── notes.txt
    └── exercises/
```

**المسار (Path)** هو عنوان الملف أو المجلد. مثال:

```text
/Users/sara/Documents/PythonCourse/notes.txt
```

تفصل العلامة `/` بين المجلدات الموجودة في العنوان.

## 2. ما الطرفية Terminal؟ (3 دقائق) 💻

**الطرفية (Terminal)** تطبيق يتيح لنا التحكم في الحاسوب بكتابة الأوامر بدلًا من النقر على الأيقونات. إنها مثل إرسال رسائل إلى جهاز Mac، لكنه حرفي جدًا ولا يفهم المزاح! 😄

لفتحها على جهاز Mac:

1. اضغط `Command (⌘) + Space`.
2. اكتب `Terminal`.
3. اضغط `Return`.

سترى سطرًا ينتظر أمرًا. يسمى هذا **موجّه الأوامر (Command Prompt)**.

جرّب هذين الأمرين الآمنين:

```bash
pwd
ls
```

- `pwd` اختصار لـ **print working directory** ويعرض موقعك الحالي.
- `ls` اختصار لـ **list** ويعرض محتويات المجلد الحالي.

أوامر مفيدة للتنقل:

```bash
cd Documents
cd ..
cd ~
```

- الأمر `cd Documents` يدخل إلى مجلد `Documents`.
- الأمر `cd ..` يصعد إلى المجلد الأب.
- الأمر `cd ~` يعيدك إلى مجلدك الرئيسي.

> **ملاحظة:** الأوامر والأسماء في الطرفية حساسة لحالة الأحرف؛ قد يكون `Documents` مختلفًا عن `documents`.

## 3. إنشاء الملفات والمجلدات (3 دقائق) ✨

أنشئ مجلدًا باستخدام `mkdir`، وهي اختصار **make directory**:

```bash
mkdir python_course
```

أنشئ ملفًا فارغًا باستخدام `touch`:

```bash
touch notes.txt
```

تحتاج الأسماء التي تحتوي مسافات إلى علامتي اقتباس:

```bash
mkdir "Python Course"
touch "day one.txt"
```

تحقق من النتيجة باستخدام:

```bash
ls
```

## 4. نسخ الملفات والمجلدات (دقيقتان) 🐑

انسخ ملفًا باستخدام `cp`، وهي اختصار **copy**:

```bash
cp notes.txt notes_backup.txt
```

انسخ ملفًا إلى مجلد آخر:

```bash
cp notes.txt python_course/
```

انسخ مجلدًا كاملًا باستخدام `cp -R`:

```bash
cp -R python_course python_course_backup
```

يخبر الخيار `-R` الطرفية أن تنسخ المجلد وكل ما بداخله. فالمجلد لديه أبناء وأحفاد، وأحيانًا 4,000 لقطة شاشة غامضة! 📸

> **تنبيه:** قد يستبدل أمر النسخ ملفًا موجودًا يحمل اسم الوجهة نفسه. استخدم `ls` لفحص الوجهة أولًا.

## 5. أمثلة محلولة (4 دقائق) ✅

### المثال الأول: إنشاء مجلد للدورة

**المطلوب:** اذهب إلى المجلد الرئيسي، وأنشئ `python_course`، ثم ادخله وأنشئ `notes.txt`.

```bash
cd ~
mkdir python_course
cd python_course
touch notes.txt
ls
```

يجب أن تتضمن النتيجة النهائية:

```text
notes.txt
```

### المثال الثاني: إنشاء نسخة احتياطية

**المطلوب:** انسخ `notes.txt` وسمِّ النسخة `notes_backup.txt`.

```bash
cp notes.txt notes_backup.txt
ls
```

النتيجة المتوقعة:

```text
notes.txt  notes_backup.txt
```

### المثال الثالث: نسخ مجلد مشروع كامل

لنفترض أن `python_course` موجود داخل `Documents`.

```bash
cd ~/Documents
cp -R python_course python_course_backup
ls
```

أصبح مجلد `Documents` يحتوي المجلدين، وبقي المجلد الأصلي دون تغيير.

## تمارين غير محلولة 🧠

لا تبحث عن إجابات خفية؛ التمارين غير محلولة عن قصد!

1. افتح الطرفية واعرض موقعك الحالي.
2. انتقل إلى مجلد `Documents` واعرض محتوياته.
3. أنشئ مجلدًا باسم `coding_practice`.
4. ادخل إليه وأنشئ ملفين: `ideas.txt` و`commands.txt`.
5. انسخ `ideas.txt` إلى ملف جديد باسم `ideas_backup.txt`.
6. ارجع إلى `Documents` وانسخ مجلد `coding_practice` كاملًا باسم `coding_practice_backup`.
7. **تحدٍّ:** أنشئ مجلدًا باسم `My Python Work` باستخدام علامتي الاقتباس، ثم أنشئ داخله ملفًا باسم `lesson one.txt`.

## مراجعة سريعة 🎯

- **الملف** يحفظ المعلومات.
- **المجلد/الدليل** ينظم الملفات والمجلدات.
- **المسار** هو عنوان العنصر.
- تستقبل الطرفية أوامر مكتوبة.
- تساعدنا `pwd` و`ls` و`cd` في التنقل.
- ينشئ `mkdir` المجلدات وينشئ `touch` الملفات.
- ينسخ `cp` ملفًا، وينسخ `cp -R` مجلدًا.

المحاضرة التالية: ما لغات البرمجة، وما أنواعها الأساسية، ولماذا تحظى بايثون بهذه الشعبية. 🐍
